# スマホで使う

現地調査アプリ（`/field/`）を、iPhone・Android から使えるようにする**手順書**。

**どの方法を選ぶかは [`docs/外から使う.md`](外から使う.md) を先に読むこと。**
このデータには被害木の位置・所有者確認のメモ・現地写真が入る。
向こうの結論は「**Tailscale が本命。公開URLに置いてはいけない**」で、
ここもそれに従う。この文書は選んだあとの手の動かし方だけを書く。

| 使い方 | 使う道具 | 位置づけ |
|---|---|---|
| 自分の端末で1回試す | cloudflared | **その場かぎり。試したら止める** |
| 職員で日常的に使う | `tailscale serve` | **本命。これにする** |
| どうしてもURLで渡す | `tailscale funnel` | 合言葉一枚が守り。おすすめしない |

---

## 1. まず知っておくこと

### なぜ「トンネル」が要るのか

スマホのブラウザは、**HTTPS でないと現在地（GPS）を使わせてくれない。**
iPhone も Android も同じで、`http://192.168.1.5:8765` のような
社内LANのアドレスでも同じく拒否される。ここに例外は無い。

現在地の出ない現地調査アプリは使いものにならないので、
無料で HTTPS を用意できる「トンネル」を1本通す。

同じ理由で、次のものも HTTPS でないと動かない。

| 機能 | HTTPS が要る理由 |
|---|---|
| 現在地・トラック記録 | Geolocation API |
| 方位（コンパス） | DeviceOrientation API |
| オフライン起動 | Service Worker |
| ホーム画面に追加 | PWA の要件 |

つまり **HTTPS でないと、このアプリはほぼ何もできない。**

### データはどこにあるのか

トンネルは「このPCへの入口」を1本作るだけで、
データを他所へ預けるわけではない。
調査記録も写真も、これまでどおり `data/survey.db` と `data/photos/` に入る。

**PCの電源が入っていないと、外から同期できない。**
ただし現地でのアプリの使用は電源と無関係に続けられる
（端末の中にたまり、次にPCが立ち上がったときに送られる）。

### 合言葉

外に出す以上、誰でも書き込める状態にはできない。
サーバーは合言葉を1つ持っていて、端末ごとに1回だけ聞く。

```
py -3 server.py --show-passphrase     いまの合言葉を見る
py -3 server.py --passphrase 好きな言葉 --show-passphrase
                                      合言葉を決め直す
```

合言葉は `data/.secret` にある。Git には入らない。
**変えると、全部の端末でもう一度聞かれる。**

## 2. とりあえず自分の端末で試す ― cloudflared

アカウント登録が要らない。**URLは起動のたびに変わる。**

> **これは「試す」ためだけのもの。**
> URLは推測できないが、インターネットに口が開く。守りは合言葉一枚しかない。
> 動くことを確かめたら `Ctrl+C` で止め、日常の運用は §3 の Tailscale にすること。
> 理由は [`docs/外から使う.md`](外から使う.md)。

### 用意

```
winget install --id Cloudflare.cloudflared
```

うまくいかないときは、公式の配布物を1つ置くだけでよい。

1. https://github.com/cloudflare/cloudflared/releases/latest
2. `cloudflared-windows-amd64.exe` を落とす（約55MB）
3. このフォルダの `bin\cloudflared.exe` という名前で保存する

### 使う

```
スマホで使う（外に公開）.bat      ← ダブルクリック
```

画面に出た URL と合言葉をスマホに入れる。

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃ スマホからこのURLを開いてください          ┃
┃   https://xxxx-yyyy.trycloudflare.com/field/ ┃
┃ 合言葉：  gg5s-rhrq-tuva                  ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

止めるときは、その画面で `Ctrl+C`。止めれば外からは一切つながらない。

## 3. 同僚と続けて使う ― Tailscale

**URLが変わらない。** 職員が何人かで使うならこちら。

### 用意（自分のPCで1回だけ）

```
winget install --id tailscale.tailscale
tailscale up                        ← ブラウザが開く。Googleなどでログイン
```

無料。個人利用の枠（100台・3ユーザーまで）で足りる。

### 公開のしかた

2通りある。**業務の性質で選ぶ。**

#### (A) 職員だけに見せる ― `tailscale serve`（おすすめ）

```
py -3 server.py --no-browser --auth
tailscale serve --bg 8765
```

`https://<PC名>.<テイルネット名>.ts.net` が出る。
**このURLは、Tailscale に入っている端末からしか開けない。**
同僚のスマホにも Tailscale を入れて、招待する。

インターネットからは到達すらできないので、いちばん安全。
合言葉との二重になる。

#### (B) 誰でも開ける ― `tailscale funnel`

```
py -3 server.py --no-browser --auth
tailscale funnel --bg 8765
```

同僚は何も入れなくてよい。URLを送るだけ。
ただし **URLを知っていれば世界中の誰でも合言葉の画面までは来る。**
合言葉だけが守り。合言葉の管理を厳しくすること。

### 自動で立ち上げる

事務所のPCを常時起動にしておくなら、
`shell:startup` に `スマホで使う（外に公開）.bat` のショートカットを置く。

## 4. スマホ側の手順

1. 送られてきた URL を **Safari（iPhone）／Chrome（Android）** で開く
2. 合言葉を入れる（この端末では次から聞かれない）
3. 位置情報を「**許可**」する
   - iPhone は「Appの使用中は許可」＋「正確な位置情報：オン」
4. **ホーム画面に追加**する
   - iPhone：共有ボタン → ホーム画面に追加
   - Android：メニュー → アプリをインストール
5. ホーム画面のアイコンから開く
   （ブラウザのタブから開くと、圏外で立ち上がらないことがある）

### 山に入る前にやること

現地は圏外。**必ず事務所のWi-Fiで先に済ませる。**

1. アプリを開く
2. `≡` → **地図を先に入れておく**
3. 調査する範囲まで地図を動かす
4. 「どこまで細かく」＝ **18**（木が見える細かさ）
5. **この範囲を保存する**

これで背景地図・標高・オルソが端末に入る。
標高が入っていれば、圏外でも「標高200m以下」の赤い塗りと
現在地の標高が出る。

### 山から下りたら

電波が戻ると自動で送られるが、
上の帯が「**同期済**」になるまでは端末を初期化しないこと。
手で送るなら `≡` → 同期 → いま同期する。

## 5. 困ったとき

| 症状 | 見るところ |
|---|---|
| 現在地が出ない | URL が `https://` か。位置情報の許可。空が見える場所か |
| 方位が出ない（iPhone） | `≡` → 方位を使えるようにする、を1回押す |
| 圏外で白い画面になる | ホーム画面のアイコンから開いているか。事前ダウンロード済みか |
| 地図が灰色 | その範囲を事前ダウンロードしていない |
| 「未接続」のまま | PCの電源とトンネルが動いているか |
| URLが変わってしまった | cloudflared は毎回変わる。Tailscale に切り替える |
| 合言葉を忘れた | PCで `py -3 server.py --show-passphrase` |

### 端末を返す・人が替わるとき

未送信が 0 になっていることを確かめてから、
ブラウザの「サイトデータを削除」をする。
未送信のまま消すと、その記録はどこにも残らない。

## 6. やっていないこと（正直に）

- **利用者ごとのアカウントは無い。** 合言葉は1つで、全員で共有する。
  誰が書いたかは担当者名の自己申告のまま。
  数人〜十数人の役所の道具として釣り合いを取った結果で、
  厳密な本人確認が要るなら `tailscale serve`（A案）を使う。
- **常時稼働のサーバーではない。** PCが落ちていると同期できない。
  現地作業そのものは止まらないので、実害は「同期が遅れる」だけ。
- **通信量の上限は見ていない。** オルソを広範囲に事前ダウンロードすると
  数百MBになる。Wi-Fiで行うこと。
