  ============================================================
   [!] Python が見つかりませんでした
  ============================================================

   このビューアーを動かすには Python が必要です。

   1. https://www.python.org/downloads/ を開く

   2. 「Download Python」をクリックしてインストーラを入手

   3. インストーラを実行するとき、最初の画面の下にある
      「Add python.exe to PATH」に必ずチェックを入れる
      （ここを入れ忘れると、この画面がまた出ます）

   4. インストールが終わったら、いったんこの画面を閉じて、
      もう一度「起動.bat」をダブルクリックしてください

  ------------------------------------------------------------
   すでに Python を入れているのにこの画面が出る場合
  ------------------------------------------------------------

   「Add python.exe to PATH」が入っていない可能性があります。
   Python を入れ直すか、コマンドプロンプトで次を実行して
   場所を確かめてください。

       where python
