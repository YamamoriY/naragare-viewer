# ナラ枯れビューアー

北海道茅部郡森町のナラ枯れ被害を、ドローンのオルソ画像の上で把握・管理するためのローカルツール。

ヘリコプターによる上空調査を置き換え、**人が現地に入れない場所を上空から確認できるようにする**ことを狙っている。

---

## これは何か

| | |
|---|---|
| 対象 | 北海道茅部郡森町（渡島総合振興局管内） |
| 動作 | ローカル完結。インターネット接続なしで動く |
| 依存 | ビューアーは **Python 標準ライブラリのみ**。GDAL / Flask / pyproj 不要 |
| データ | 外部に一切送信しない |

オルソの取り込みだけ `pillow` と `numpy` が要る。

---

## 使い方

```
起動.bat                          ← ダブルクリックで起動
初期設定（最初に一度だけ）.bat      ← 新しい端末で最初に1回
```

新しいオルソは、画面右上の「＋ オルソを取り込む」から取り込む。
GeoTIFF、または JPEG/PNG ＋ ワールドファイル（.jgw）に対応。

くわしくは [`docs/運用マニュアル.md`](docs/運用マニュアル.md)。

---

## できること

- ドローンのオルソを地図タイル化して表示（Webメルカトル XYZ）
- 木ごとの **現地調査ステータス**管理
  （未調査／被害あり／被害なし／判定保留／**到達できず**／処理済）
- 緯度経度・度分秒・**平面直角座標系XI系**の3形式表示とコピー
- オルソをタップして木を登録、ピンをドラッグして位置を補正
- 森林調査簿から **林班・小班・樹種・代表地番・標高** を自動付与
- カシノナガキクイムシ脱出前（**翌年5月末**）までの処理期限管理
- CSV（Excel）／GeoJSON（QGIS）書き出し
- 距離計測・現在地・座標ジャンプ・オフライン背景地図

**候補木の自動抽出は既定では行わない。** 抽出は別のアルゴリズムで行い、
後からデータベースにマージする前提。同梱の色ベース抽出を使うときは `--detect`。

---

## 背景

ナラ枯れは、カシノナガキクイムシが媒介するナラ菌でミズナラ・コナラ・カシワが枯死する被害。
北海道では **令和5年(2023)10月に道南で初確認**され、令和7年度には道内11市町で2,001本が確認された。

森町では **令和8年(2026)5月13日、砂原2丁目の町有林1020林班**で被害木が確認され、
町は **標高200m以下**を重点管理地域に設定している。

渡島総合振興局が整理した森町の現地確認結果では、**11地点のうち5地点が到達不能**
（笹薮1.5km以上／高低差100mの急斜面／熊の足跡）で、
実際にナラ枯れだったのは1地点だけだった。

**到達不能だった5地点のうち4地点が、今回のオルソの範囲に入っている。**

くわしくは [`docs/背景と設計.md`](docs/背景と設計.md)。

## 構成

```
起動.bat / オルソを取り込む.bat / 初期設定（最初に一度だけ）.bat
server.py              HTTP + JSON API（標準ライブラリのみ）
app/                   画面（Leaflet 同梱・オフライン動作）
tools/
  geo.py               平面直角座標系XI系 ⇄ 緯度経度 ⇄ Webメルカトル
  shapelib.py          shapefile / dbf / xlsx リーダ（標準ライブラリのみ）
  ortho.py             オルソ読み込みと XYZ タイル化
  dem.py               国土地理院 標高タイル
  detect.py            色ベースの候補抽出（既定では使わない）
  build_forest.py      北海道オープンデータ → forest.db
  ingest_ortho.py      オルソ取り込み
  ...
docs/                  運用マニュアル / 背景と設計 / 引き継ぎ
data/                  ※大きいものは .gitignore で除外
```

GDAL を使わずに済ませるため、投影計算（Krüger級数6次）・shapefile読み込み・
GeoTIFFタグ解析・タイル化を自前で実装している。
投影計算は実測値と照合し **誤差7cm以内**（`py -3 tools/geo.py` で検証できる）。

## 座標系

| データ | 座標系 |
|---|---|
| ドローンオルソ・DSM | EPSG:6679（JGD2011 平面直角XI系） |
| 林班・小班（北海道オープンデータ） | EPSG:2459（JGD2000 平面直角XI系） |

投影パラメータが同一（lat_0=44, lon_0=140.25, k=0.9999, GRS80）のため直接重ねられる。

---

## 位置の精度（重要）

オルソは **GCP も RTK も使っていない GPS 単独測位**で作られている。

- オルソ内部の形状・距離は正確
- **絶対位置に水平 ±3〜5m の系統的なずれ**が残る
- **境界確定・図面作成には使用できない**

林分の現況把握・変化の把握・作業計画の検討が想定用途。

## データの出典

| データ | 出典 | 条件 |
|---|---|---|
| 林班・小班・森林調査簿 | 北海道オープンデータ「森林計画関係資料（一般民有林）令和6年 渡島」 | 北海道オープンデータ利用規約 |
| 標高（DEM10B）・空中写真・地形図 | 国土地理院タイル | 国土地理院コンテンツ利用規約 |
| 被害状況 | 北海道水産林務部／森町農林課の公表資料 | 出典明記のうえ引用 |
| Leaflet 1.9.4 | https://leafletjs.com | BSD-2-Clause |

森林計画関係資料は間接調査法により作成されたもので、
所有権等の諸権利・所有界・面積・木竹の評価を証明するものではない。
